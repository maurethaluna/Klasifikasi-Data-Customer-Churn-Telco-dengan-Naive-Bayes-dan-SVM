# Klasifikasi Data Customer Churn Telco dengan Naive Bayes dan SVM
Membandingkan Naive Bayes dan SVM dalam memprediksi customer churn pada dataset Telco Customer Churn, melalui preprocessing data, pembagian data training dan testing 70:30, serta optimasi SVM dengan Grid Search dan cross validation, hasilnya SVM unggul pada akurasi dan stabilitas, Naive Bayes lebih baik mendeteksi churn dengan recall lebih tinggi

Perbandingan kinerja dilakukan antara metode Naive Bayes dan Support Vector Machine (SVM) berdasarkan hasil evaluasi pada data testing. Perbandingan Accuracy Naive Bayes dengan SVM Berdasarkan hasil pada tabel, terlihat bahwa metode Support Vector Machine (SVM) dengan parameter optimal memberikan nilai akurasi tertinggi sebesar 0,796025 dibandingkan metode Naive Bayes. Dari hasil confusion matrix , metode Naive Bayes menunjukkan kemampuan yang lebih baik dalam mendeteksi kelas churn dengan nilai recall sebesar 0,78, tetapi menghasilkan cukup banyak kesalahan klasifikasi pada kelas non-churn . Sebaliknya, metode SVM memiliki nilai recall yang lebih tinggi pada kelas non-churn (0,91) dengan nilai recall pada kelas churn relatif lebih rendah (0,49). Secara keseluruhan, metode SVM unggul dalam akurasi dan kestabilan model, terutama dalam mengklasifikasikan kelas mayoritas. Namun, metode Naive Bayes lebih sensitif terhadap kelas churn sehingga lebih efektif dalam mendeteksi pelanggan yang berpotensi berhenti berlangganan. 

Berdasarkan hasil analisis, terlihat bahwa metode Support Vector Machine (SVM) lebih efektif untuk analisis kelas data yang jumlahnya banyak dan kurang efektif untuk analisis kelas data yang jumlahnya sedikit. Hal ini menyebabkan hasil akurasi tinggi dan model yang stabil. Sebaliknya, metode Naive Bayes lebih efektif untuk analisis kelas data yang jumlahnya sedikit dan kurang efektif untuk analisis kelas data yang jumlahnya banyak. Hal ini menyebabkan hasil akurasi rendah dan model yang kurang stabil.
